# Přehled kontrol a assertů v automatizovaných testech (Test Assertions Overview)

Tento dokument detailně popisuje veškeré kontroly (`asserty` / `expect`), které jsou implementovány v jednotlivých testech napříč všemi 6 moduly aplikace Demo-login.
Využívá se výhradně **doporučená nativní metoda Playwrightu `page.get_by_test_id("...")`**, **řetězení kontejnerů** a **víceúrovňové ověřování stavu**.

---

## 📌 Strategie ověřování (Proč pouhé URL nestačí)

V profesionální testovací automatizaci se uplatňuje pravidlo víceúrovňové validace:
1. **Směrování (Routing):** `expect(page).to_have_url(...)` – ověří změnu URL adresy.
2. **Stav uživatelského sezení (Session):** `expect(navbar.logout_button).to_be_visible()` / `.not_to_be_visible()` – jednoznačný důkaz existence/zániku autorizační relace.
3. **Kontextová data (Data State):** `expect(welcome_section).to_contain_text(user_name)` – ověří, že server vrátil data příslušející právě přihlášenému uživateli.
4. **Formulářové validace:** `expect(error_locator).to_have_text(...)` – ověří chybové stavy bez falešně pozitivních výsledků.
5. **Bezpečnostní integrita:** `assert has_security_cookie`, `assert session_after != session_before` – ověří CSRF tokeny a regeneraci session ID.
